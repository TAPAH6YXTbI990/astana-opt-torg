# Полный перечень библиотек и определение, где используются

## Основные зависимости (production)

### FastAPI
- **Версия:** >= 0.115, < 1.0
- **Назначение:** Веб-фреймворк для создания HTTP API
- **Где используется:** `app.py` — создание приложения, маршрутов, обработка входящих webhook-запросов от Bitrix24

### uvicorn
- **Версия:** >= 0.30, < 1.0 (с extras `standard`)
- **Назначение:** ASGI-сервер для запуска FastAPI приложения
- **Где используется:** Команда запуска `uvicorn bitrix_chat.main:app`

### fast-bitrix24
- **Версия:** >= 1.8.12
- **Назначение:** Асинхронный клиент для Bitrix24 REST API, автоматически обрабатывает rate-limit и пакетные вызовы
- **Где используется:** `bitrix_client.py` — клиент `Bitrix` для вызовов методов `imbot.v2.*` и `imconnector.*` через webhook URL

### python-dotenv
- **Версия:** >= 1.0, < 2.0
- **Назначение:** Загрузка переменных окружения из файла `.env`
- **Где используется:** `config.py` — функция `get_settings()` вызывает `load_dotenv()` перед чтением переменных; `register_bot.py` и `bind_openlines.py` — CLI утилиты

## Стандартная библиотека Python (используемые модули)

| Модуль | Где используется |
|--------|-----------------|
| `json` | Сериализация/десериализация payload в `app.py`, `oauth_client.py`, `handlers.py`, `payloads.py` |
| `logging` | Структурированное логирование во всех модулях |
| `dataclass` | Определение моделей данных: `Settings`, `BitrixClient`, `OAuthBitrixClient`, `AppAuth`, `HandleResult`, все модели событий в `events.py` |
| `os` | Чтение переменных окружения в `config.py` |
| `pathlib` | Работа с файловым путём хранилища токенов в `app_auth.py` |
| `threading.Lock` | Потокобезопасный доступ к файлу токенов в `app_auth.py` |
| `time` | Генерация timestamp для исходящих сообщений в `handlers.py` |
| `uuid` | Генерация уникальных ID исходящих сообщений в `handlers.py` |
| `urllib.request` | HTTP-запросы к REST API и внешнему сервису в `oauth_client.py` и `handlers.py` |
| `urllib.parse` | Кодирование form-data (`urlencode`) в `oauth_client.py`, парсинг query string (`parse_qs`) в `payloads.py` |
| `urllib.error` | Обработка HTTP ошибок (`HTTPError`, `URLError`) в `oauth_client.py` |
| `argparse` | CLI интерфейс в `register_bot.py` и `bind_openlines.py` |
| `typing` | Type hints (`Any`, `dict`, `list`) во всех модулях |
| `__future__` | Аннотации отложенного вычисления (`from __future__ import annotations`) во всех модулях |

## Стандартная библиотека — детализация по модулям

### Модули, используемые в `app.py`
- `json` — сериализация payload для логов
- `logging` — настройка уровня и формата логирования, получение логгеров

### Модули, используемые в `handlers.py`
- `dataclass` — `HandleResult` с полями `handled`, `reason`, `echoed_text`
- `json` — кодирование запроса к внешнему сервису
- `logging` — логирование всех этапов обработки
- `time` — `int(time())` для timestamp исходящих сообщений
- `uuid` — `uuid4().hex` для уникальных ID сообщений
- `urllib.request.Request` — формирование HTTP-запроса к внешнему вебхуку
- `urllib.request.urlopen` — отправка запроса к внешнему сервису

### Модули, используемые в `oauth_client.py`
- `dataclasses.asdict` — преобразование AppAuth в dict для обновления токенов
- `dataclasses.dataclass` — `OAuthBitrixClient`
- `json` — кодирование тел запросов, декодирование ответов
- `logging` — логирование REST-вызовов
- `typing.Any` — типизация возвращаемых значений
- `urllib.error.HTTPError` — обработка HTTP ошибок, автоматический refresh токена при 401
- `urllib.error.URLError` — обработка сетевых ошибок
- `urllib.parse.urlencode` — формирование тела для refresh token запроса
- `urllib.request.Request` — формирование HTTP-запросов
- `urllib.request.urlopen` — отправка HTTP-запросов

### Модули, используемые в `events.py`
- `dataclass` — модели `IncomingEvent`, `OpenLineEvent`, `OpenLineMessage`, `ConnectorEvent`, `ConnectorMessage`, `AppInstallEvent`
- `typing.Any` — типизация данных из неструктурированных payload

### Модули, используемые в `app_auth.py`
- `dataclasses.asdict` — сериализация `AppAuth` в JSON
- `dataclasses.dataclass` — `AppAuth`
- `json` — чтение/запись JSON файла токенов
- `pathlib.Path` — работа с файловой системой
- `threading.Lock` — потокобезопасная запись/чтение файла
- `typing.Any` — типизация `from_mapping()`

### Модули, используемые в `bitrix_client.py`
- `dataclass` — `BitrixClient`
- `typing.Any` — типизация возвращаемых значений REST-вызовов
- `logging` — логирование отправленных сообщений

### Модули, используемые в `payloads.py`
- `json` — парсинг JSON тела запроса
- `urllib.parse.parse_qs` — парсинг URL-encoded тела запроса
