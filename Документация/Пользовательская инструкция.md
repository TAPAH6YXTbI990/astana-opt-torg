# Пользовательская инструкция

## Что делает этот бот

Это webhook-бот для Bitrix24, который:
- Обрабатывает сообщения открытых линий, пересылая их во внешний сервис для генерации ответов
- Автоматически сохраняет токены при установке приложения в Bitrix24

---

## Быстрый старт

### Требования

- Python 3.12 или выше
- Пакетный менеджер `uv` (рекомендуется)
- Публичный домен с HTTPS (для работы webhook)
- Аккаунт Bitrix24 с правами администратора

### Шаг 1: Установка зависимостей

```bash
uv sync
```

### Шаг 2: Создание файла .env

Скопируйте пример конфигурации и заполните значениями:

```bash
cp .env.example .env
```

Получить необходимые значения:

1. **BITRIX_REST_WEBHOOK_URL** — Администрирование → Разработчикам → Другое → Входящий вебхук
2. **BITRIX_BOT_ID** и **BITRIX_BOT_TOKEN** — зарегистрируйте бота командой (см. шаг 3)
3. **BITRIX_CLIENT_ID** и **BITRIX_CLIENT_SECRET** — Администрирование → Разработчикам → Другое → Локальное приложение
4. **BITRIX_INBOUND_SECRET** — придумайте любую секретную строку
5. **BITRIX_APP_WEBHOOK_URL** — соберите из вашего домена: `https://your-domain/webhooks/bitrix24/app/{BITRIX_INBOUND_SECRET}`

### Шаг 3: Регистрация бота

```bash
uv run bitrix-register-bot \
  --code echo_bot \
  --name "Echo Bot" \
  --bot-token ваш_токен \
  --webhook-url https://your-domain.example/webhooks/bitrix24/ваш_секрет
```

В ответе будет JSON с `bot.id`. Запишите его в `BITRIX_BOT_ID` в `.env`.

### Шаг 4: Запуск сервера

```bash
uv run uvicorn bitrix_chat.main:app --host 0.0.0.0 --port 8000
```

### Шаг 5: Настройка webhook в Bitrix24

1. Откройте Bitrix24 → Администрирование → Разработчикам → Другое
2. Добавьте webhook-обработчик
3. URL: `https://your-domain.example/webhooks/bitrix24/openlines/ваш_секрет`
4. Событие: `ONIMCONNECTORMESSAGEADD`

## Привязка событий Open Lines (CLI)

Если приложение было установлено до добавления функциональности автоматической привязки:

```bash
uv run bitrix-bind-openlines --handler https://your-domain.example/webhooks/bitrix24/app/your-secret
```

Если `BITRIX_APP_WEBHOOK_URL` уже настроен, можно без параметров:

```bash
uv run bitrix-bind-openlines
```

## Режимы работы

### 1. Обработка Open Lines

Бот принимает сообщения `ONOPENLINEMESSAGEADD` и:
1. Пересылает текст во внешний сервис (POST-запрос)
2. Получает ответ от внешнего сервиса
3. Отправляет ответ пользователю через `imopenlines.bot.session.message.send`

Для работы необходимо настроить `BITRIX_OPENLINE_RESPONSE_WEBHOOK_URL`.

### 2. Установка приложения (при создании локального приложения через битрикс)

При получении `ONAPPINSTALL` бот:
1. Сохраняет OAuth-токены приложения в файл
2. Автоматически привязывает событие `ONOPENLINEMESSAGEADD`

## Формат взаимодействия с внешним сервисом

### Запрос от бота

**URL:** `BITRIX_OPENLINE_RESPONSE_WEBHOOK_URL`  
**Метод:** POST  
**Content-Type:** application/json

```json
{
  "message": "Текст сообщения пользователя",
  "session_id": "ID пользователя в Bitrix24"
}
```

### Ответ внешнего сервиса

**Content-Type:** application/json

```json
{
  "output": "Текст ответа для пользователя"
}
```

## Архитектура webhook URL

Проект использует три webhook URL, различающихся только префиксом пути:

| URL | Назначение |
|-----|-----------|
| `/webhooks/bitrix24/{secret}` | События ботов (ONIMBOTV2MESSAGEADD) |
| `/webhooks/bitrix24/openlines/{secret}` | События Open Lines (ONOPENLINEMESSAGEADD) |
| `/webhooks/bitrix24/app/{secret}` | Установка приложения + Open Lines |

Все три endpoint поддерживают GET, POST, HEAD методы. Секрет в URL проверяется, невалидный секрет возвращает 404.

## Частые проблемы

### Бот не отвечает в чате
- Проверьте, что сервер запущен и доступен
- Проверьте `BITRIX_REST_WEBHOOK_URL` — он должен быть валидным
- Проверьте `BITRIX_BOT_ID` и `BITRIX_BOT_TOKEN` — они должны совпадать с зарегистрированным ботом
- Проверьте `BITRIX_INBOUND_SECRET` — он должен совпадать с токеном в URL webhook

### Бот не обрабатывает Open Lines
- Проверьте, что событие `ONOPENLINEMESSAGEADD` привязано через `event.bind`
- Проверьте `BITRIX_APP_WEBHOOK_URL` — он должен быть доступен из Bitrix24
- Проверьте токены приложения в файле `BITRIX_APP_STATE_PATH`

### Ошибка «Application auth is not installed yet»
- Приложение ещё не установлено в Bitrix24
- Установите приложение через маркетплейс Bitrix24 или вручную

### Ошибка 401 при вызовах REST API
- Токен доступа истёк — бот автоматически обновит его при следующем вызове
- Если ошибка повторяется — переустановите приложение
